# このブラウザのパスワード保管庫（0.11）

「設定 → パスワード」から開きます。端末にパスコードを設定し、Face IDまたは端末パスコードで認証してください。Appleの「パスワード」とは別の端末専用保管庫です。Apple側の登録や自動入力の設定は変更しません。

ログインフォームがあるページには「パスワード」ボタンが現れます。メニューの「パスワード」からも利用できます。保管庫を開き、そのサイトのアカウントを選ぶと入力します。ログインの送信は利用者が行います。入力済みフォームを登録する場合は「このフォームの入力内容を確認して保存」を選び、内容を確認して保存します。入力内容の常時収集やログインの自動保存は行いません。新規アカウントの手動追加・編集・個別削除に対応します。

入力ボタンの表示、プライベートタブへの入力許可（初期オフ）、自動ロック30秒／1分（初期値）／5分を設定できます。プライベートタブからの保存は行いません。バックグラウンドで即ロックし、認証中やアプリ切り替え時の保管庫画面は覆います。無操作に限らず、ロック解除または保存から設定時間が経つと再認証が必要です。

## Safari・Braveからの取り込み

1. 元のブラウザ／パスワード管理画面でパスワードを書き出します。Safari／AppleのパスワードCSV、パスワードCSVを含むSafariのZIP、BraveのCSVに対応します。iPhoneのOS／ブラウザの版に書き出し機能がなければ、同期済みMac／Windows版など対応する環境で行ってください。
2. iPhoneの「ファイル」から選べる場所に保存します。これは平文の秘密情報です。チャット、GitHub、共有リポジトリには送らないでください。
3. このアプリの「設定 → パスワード」で認証し、「Safari・Braveのパスワードを取り込む」から選びます。
4. 件数、除外、重複、既存内容との競合を確認します。初期状態では同じサイト・ユーザー名の既存内容を保持します。置換したい場合だけスイッチをオンにして「確認して取り込む」を押します。
5. ログインページで入力を試した後、平文CSV／ZIPを不要な転送先と「最近削除した項目」からも削除します。元ブラウザのパスワードは自動削除されません。

必須列はURL・ユーザー名・パスワード。表示名とメモも取り込みます。UTF-8、BOM付きUTF-16、引用符・カンマ・改行・日本語に対応し、パスワードの前後空白やUnicodeの文字の並びを変更しません。ユーザー名とパスワードの同一性はUTF-8の値で比較します。パスキー、確認コードの秘密鍵、Cookie、セッションは移行しません。上限は保管庫5,000件、CSV8MiB、ZIP入力20MiB・選択した展開データ16MiBです。URLが不正な行や空のパスワードは除外します。閲覧データ用の従来の取り込みは、引き続きパスワードを読みません。

## 保護とバックアップ

保存ファイル全体をAES-256-GCMで暗号化し、ランダムな鍵はKeychainの端末パスコード必須・端末認証付き・この端末専用項目に置きます。保管庫は通常の閲覧データと別のディレクトリに保存し、端末バックアップから除外します。閲覧データJSON、UserDefaults、通常の書き出し、GitHub、配信JSONへ秘密を入れません。パスワードのクラウド同期や平文書き出しはありません。

自動入力は通信方式・ホスト・ポートが完全一致するHTTPS、システムが信頼する証明書、混在コンテンツのない選択中ページに限定します。サブドメインや別ポートは別登録です。証明書例外を認めて閲覧したサイトやHTTPサイトには入力しません。別サイトのiframe、別サイトへ送信するform、隠れた入力欄、新規パスワード用の欄への通常入力を避けます。認証後や入力前後にもページ識別を確認し、ページの更新・移動による取り違えを中止します。Webページには入力後の値を読めるため、正しいサイトであることは利用者自身でも確認してください。通常のサイトと違う独自フォーム、閉じたShadow DOM、二段階フォームなどには対応できない場合があります。

SideStoreでは同じApple Account・Bundle IDでの上書き更新を続け、アプリを削除しないでください。署名のTeam ID／アクセスグループが変わる、端末パスコードを解除する、アプリや端末を失うとKeychainの鍵が使えなくなる場合があります。旧バージョンには新保管庫機能がないため、コードを戻しても保管庫ファイルを削除・旧版データへ戻しません。

「暗号化バックアップを書き出す」で12文字以上の専用パスフレーズを設定してください。ランダムsalt、PBKDF2-HMAC-SHA256（600,000回）、AES-256-GCMで暗号化したJSONのみを書き出します。パスフレーズを別に安全に保管してください。忘れると復号できません。

ロック解除できる場合、バックアップの読み込みは既存の内容を保ったまま結合します。解除できない場合はロック画面の「暗号化バックアップから復元」から読み、パスフレーズ入力・保管庫置換の確認・端末認証を経て新しい端末鍵を作成します。元ファイルを勝手に初期化する処理はありません。

追加の有料Entitlement、iCloud、App Group、資格情報プロバイダー拡張は使いません。現在の無料署名構成を維持します。
