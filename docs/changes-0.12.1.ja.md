# 0.12.1 画面レイアウトの修正

0.12.0 build70への更新後、画面が真っ暗になり、下部ツールバーが下にずれすぎてブラウジングできないとの実機報告を受けた修正。

- 開発用の保管庫ボタンを載せるsafeAreaInsetは、DEBUGかつ専用fixtureのときだけ構築する。Releaseでボタンだけを除去して空のinsetを残す構成をなくした。
- Web表示とパスワード候補欄を同じ縦スタック内に置き、候補欄の実際の高さを引いた残りをWeb表示へ割り当てる。明示的なWeb表示フレームにsafeAreaInsetを重ねる構成をなくした。非表示時の候補欄も縦方向へ伸びないようにする。
- Release構成のSimulatorで、専用アプリ内fixtureや認証バイパスを使わず、アドレス入力から実際のHTTPページを開く回帰テストを追加。ページの高さ、下部アドレス/メニューボタンの画面内配置、DOMボタンの操作、縦横回転後の操作を確認する。
- 既存のパスワード候補/入力、ホーム、検索候補、バー表示操作も関連ケースのみ確認する。全UIスイートや旧IPAの再取得は行わない。

保存形式、アプリID、保管庫の鍵/暗号文、Cookie、ブックマーク、履歴を変更しない。修正版は既存アプリに上書きする。アプリの削除は不要。

配布版構成のSimulator確認とユーザー実機での確認は区別する。実機での改善は更新後の観察が必要。
