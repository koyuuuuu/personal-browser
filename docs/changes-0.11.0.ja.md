# 0.11.0 パスワード保管庫と選択式自動入力

ブラウザ専用の暗号化保管庫、端末認証、手動登録・編集・削除、現在のログインフォームへの選択式入力と確認保存、Safari／BraveのCSV・Safari ZIP取り込み、暗号化バックアップを追加しました。設定画面とメニューに「パスワード」を追加しています。自動送信やバックグラウンドのフォーム内容収集は行いません。Appleのパスワード連携は変更していません。

[使い方・取り込み・バックアップ・制約](password-vault.ja.md)。通常のライブラリとは独立した暗号化ファイルと端末認証付きKeychainを使用します。入力はHTTPSの信頼できる証明書・混在コンテンツなし・完全一致origin・同一originのフレームに限定し、認証後の移動も確認します。無料署名に追加Entitlementは不要です。

既存のBundle ID、閲覧データschema1、Cookieストア、タブ・履歴・ブックマーク・既存設定は維持します。build14のメディア処理と後続の音声機能は変更していません。直前の0.10.1 build60と過去のタグ・IPAは保持します。

検証は入力元の境界、CSVの引用符・文字・長さと重複処理、暗号化／改ざん検知／バックアップ、専用ZIP選択と従来のパスワード除外のCore試験、関連UI1件、変更したZIP選択の保存互換性、実機用IPAビルドに限定します。UI試験ではDebug限定の固定ローカルフォーム・テスト認証鍵を使い、実際の暗号化ファイルへの保存、ロック・再読込、取り込み・選択入力・非自動送信を確認します。Releaseにはテスト鍵・認証省略・HTTP入力許可は含まれません。実機のFace ID／Keychainアクセス制御・Safari／Braveの実データはCIで検証したものとは扱いません。

配信済み版は **0.11.0 build65**（ソース `2a8e4d4134e3f42daf416dd26b919ab7fc385597`）。Python55件・Core77件・関連UI1件・条件付き互換性・実機用ビルドと配信照合に成功しました。[検証記録](validation-0.11.0-2026-11-08.json)。
