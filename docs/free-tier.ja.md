# GitHubの無料枠でできること

確認日: 2026-10-22（日本時間）。GitHub Freeを前提とする。ユーザーのプラン・残り枠・支払い設定はまだ参照していない。

決定済みの運用方針: 非公開リポジトリで開始し、無料枠内で利用、超過する有料利用は停止する。アカウント側の停止設定が完了したことは、まだ確認していない。

## 無料枠は機能制限ではなく利用量の上限

非公開リポジトリでも、ソース管理、iOSアプリのビルド、単体テスト、SimulatorのUIテスト、未署名IPA生成ができる。無料枠の違いによって、ブラウザに追加できる機能が減るわけではない。

| 項目 | GitHub Freeの条件 | 今回の使い道 |
|---|---|---|
| 非公開リポジトリのActions実行 | 月2,000分の枠。アカウント内の利用で共用 | クラウドでのコンパイル・テスト |
| 成果物ストレージ | 500MB相当の枠。時間を含む使用量で計算され、GitHub Packagesと共用 | IPA・ビルド記録・失敗ログ |
| Actionsキャッシュ | リポジトリ単位の別枠。現在10GB | 現在のCIでは使わない |
| 公開リポジトリの標準ランナー | ランナーの実行時間は無料 | macOSで繰り返しビルドする場合に有利 |

出典: [プランごとの無料枠](https://docs.github.com/en/billing/reference/product-usage-included)、[Actions課金](https://docs.github.com/en/billing/concepts/product-billing/github-actions)。

## 2,000分を、そのままMacの実行時間と考えない

OSやランナー種類で消費条件が異なり、macOSはLinuxより高い。現在の公式ページの標準macOS超過単価は$0.062/分だが、**この超過単価だけから無料枠のMac実行時間を逆算しない**。初回のビルド時間とBilling画面での実際の消費を確認して回数を決める。

例えば、仮に1回のビルドが無料枠を100分分消費する条件なら、残り2,000分で20回になる。これは計算例で、今回のビルドが100分分を使うと実測したものではない。失敗や再実行も消費するため、初期のエラー修正が多い時期ほど枠が減りやすい。

出典: [ランナー料金](https://docs.github.com/en/billing/reference/actions-runner-pricing)。

## 消費しないもの

- Windowsでコードを編集している時間。
- インストール済みアプリをiPhoneで使う時間。
- SideStoreによる署名更新。新しいIPAを毎週ビルドする必要はない。

Actionsの枠を使い切っても、インストール済みアプリがその理由で停止することはない。Apple署名の有効期限は別で、SideStoreでの再署名を継続する必要がある。

## このプロジェクトの初期運用

小さな変更の検査とCoreテストはLinuxで実行する。現在はLinux・macOSとも手動起動だけに限定し、push/PRでは実行しない。アカウントの課金停止設定を確認した後、必要に応じてLinux検査の自動実行を追加する。費用消費の大きいmacOSは手動実行を維持する。1回のmacOS実行でCoreテスト、Simulator UIテスト、任意でIPA生成まで行う。

IPAと失敗ログの保持期間は1日。例えば20MBのIPAを5個保持するだけなら約100MBだが、他の成果物・Packages・保持時間も考慮する。実際のIPA容量は初回ビルド後に測定する。大きなDerivedDataやSimulatorイメージはアップロードしない。

非公開で始め、必要な変更をまとめてビルドする運用は可能。開発中に頻繁な実機用ビルドが必要になったときは、無料枠の翌月リセットを待つか、公開へ変更するかを選べる。自動的に課金へ切り替える設定にはしない。

## 無料枠を超えた場合

支払い方法が登録されていなければ、公式資料では無料枠超過後の使用がブロックされる。支払い方法がある場合は、該当するActionsとストレージの予算で「Stop usage when budget limit is reached」を有効にし、追加課金を許可しない設定を本人が確認する。通知だけの設定では停止しない。

課金設定はGitHubアカウント側の設定で、リポジトリのYAMLだけでは完全に制御できない。設定確認後に最初のmacOSビルドを実行する。

Codexの利用枠・AI API料金、Appleの署名期限、SideStoreは、このGitHub Actions無料枠とは別である。
