# 0.16.1 タブ一覧の連続遷移

選択中タブの青枠（プライベートは紫）を、ライブサイト表示より上に置く独立した非操作レイヤーへ移した。カードの見出しと本文を含む外枠に追従し、一覧のスクロール範囲で切り抜く。

一覧の位置報告が繰り返されてもアニメーションを開始し直さない。拡縮するのは選択中の1枚だけとし、ほかのライブタブは最初に一覧の位置へ配置して固定する。一覧全体のフェードと、他タブを一緒に縮めるマスクを廃止した。

WKWebView自体の表示領域・変形・スクロール位置を遷移中に変更せず、同じ親コンテナの変形と切り抜きだけを動かす。現在のページとプレーヤーは同じウィンドウに保持し、動画の静止画像への置換や再読み込みを行わない。非表示ページの画素はマスクで遮り、薄い全画面ページが一覧へ重なるのも防ぐ。ホーム画面だけは従来どおり端末内の一時スナップショットを用いる。

関連するネイティブ検証は、実際の動画画素・再生進行、両辺の青枠画素、描画フレームごとの現在ページの同一性・固定表示領域・単調な拡縮・他タブの固定・枠の重なり、既存の初期選択／削除／回転／パスワード／Releaseページ操作を対象にする。診断はDEBUGかつ2つの起動フラグが揃う場合だけ有効で、画面領域の予約を行わない。提供された録画は調査環境だけで確認し、公開リポジトリやCIへ含めない。

bundle ID、schema1、ブックマーク・履歴・タブ・保管庫の保存形式、build14メディア処理と0.16のバックグラウンド音声機能は変更しない。実機での見た目の受け入れと、制御されたシミュレーター検証は区別する。

0.16.1 build104を配信済み。Python62件・Core85件・関連Debug UI4件・Release UI1件・実機用ビルド・匿名配信照合に成功。青枠の両辺の画素、動画画素と再生の進行、2回の往復で実際の描画フレームの固定表示領域／他タブの固定／単調な拡縮／枠の前面を確認した。製品版に検証用フラグや動画は含まれない。実機での見え方は未確認。[検証記録](validation-0.16.1-2026-11-23.json)。
