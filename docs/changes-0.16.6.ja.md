# 0.16.6 全画面開始の注意書き

前版はページの全画面APIを置き換えていたが、WebKitのElement Fullscreen設定は有効なままだった。置換を通らないネイティブ呼び出しが標準の全画面通知へ到達できるため、公開設定isElementFullscreenEnabledもfalseにする。通知を消す非公開APIやOSビューの探索は使わない。

全画面APIが設定により公開されない環境でも、サイトの機能判定・全画面対象・終了操作・イベントハンドラーをアダプターが提供する。HTMLElementなどの固有の接頭辞付き関数も置換する。元の動画の公開ネイティブ全画面、または元の要素のPopover／アプリ内全画面へ処理する。動画全画面呼び出しが利用不可なら同じ要素でアプリ内全画面に切り替える。再生要素・URL・ログイン情報・保存データは変更しない。

iframeの所有元とallow属性、利用できるPermissions Policy、ユーザー操作を確認する。親の許可は操作前に問い合わせ、許可されない子フレームからアプリ全体を拡大しない。PiP中のDOM・表示領域保持と遅延終了処理、音声方針は維持する。

ローカルChromiumで標準API欠落、固有プロトタイプの関数、イベント、動画全画面呼び出し失敗時の代替、権限拒否、iframe、元の動画のデコード進行、PiP状態での表示保持を確認する。iOS動画／PiPは模擬であり、実機の注意書きや当該サイトを再現した確認ではない。サイト独自のHTML表示やOSの許可・認証通知まで一律削除する変更ではない。

利用者の実機テスト希望を引き継ぎ、長いiOS UIテストは省略。Release実機用ビルド・IPA検査・公開配信と取得照合を行う。通常CIは変更しない。
