# 0.4.2 操作と履歴の改善

## 変更点

- 横画面ホーム：背景画像はタッチを受け取らず、ホームとWebViewの領域を現在のビューポートに限定。バーを上の表示・操作階層に置く。
- タブ一覧：UICollectionViewの差分更新に変更。左スワイプが削除しきい値（幅の38%、最大80pt）を越えた時点で削除し、約0.22秒で周囲のセルを移動。短い高速フリックにも対応。指を離すまで待たない。画像は縮小・デコードしてメモリキャッシュし、スワイプ中のJPEG再デコードを避ける。画像ファイル削除は通常の保存処理で行う。
- アドレスバー左右スワイプ：プレビューが指に追従し、確定・取り消しを約0.20秒で完了。最後から次へ進むと新しいタブ。実際のWebViewを変形・移動せず、非操作の画像だけを動かす。プラスボタンによる追加には横スライドを付けない。
- 履歴：端末の暦・タイムゾーンに沿って午前／午後の最大2フォルダに分類。日付をタップして展開。左スワイプの×で半日分を削除、各ページも個別削除。検索中は該当項目を展開する。
- メニュー：表示順を固定し、ダウンロード、その下に設定を配置。
- Safari取り込み：数値HTML文字参照（日本語・絵文字）、BOM付きUTF-16/32、明示されたShift_JIS等の文字コードを読み取る。不明な不正UTF-8を推測変換して保存しない。既存の文字化け項目を推測で一括書き換えることはしない。
- 倍率：主ツールバー・アドレスバー左右に「ページを5％拡大／縮小」を配置可能。75〜200％の範囲で1回5ポイントずつ変更。新しいボタンの設定はtoolbar.jsonに保存し、古いバージョンの設定読み込みを妨げない。
- アドレス候補：入力が履歴タイトルまたはURLに部分一致したらURLとタイトルを候補表示。候補タップで開く。端末内の履歴のみを検索し、外部へ入力を送信しない。
- 縦横のバー：下へ読み進める指操作で隠れ、上へ戻る指操作で表示。最下部の慣性・跳ね返り、レイアウト変更では表示しない。

## データと再生

bundle ID、browser.json schema 1、現在のブックマーク・履歴・お気に入りとタブ画像の保存場所を維持。再生処理はbuild 14方式を維持。公開先にはIPAと配信データのみを置く。

## 検証

ネイティブCI実行後に結果を追記。自動操作では回転、縦長背景を配置したホームでの実タップ、連続タブ削除、再起動後の画像、履歴の午前午後別削除、候補、倍率保存、末尾スクロールを確認する。iPhone実機での体感フレームレートをシミュレータ結果だけで保証しない。
