# 0.6.0：広告フィルターとサイトアイコン

## 広告ブロック

従来の20ドメインの固定ルールから、EasyList・EasyPrivacy・AdGuard Japanese filterを変換したルールへ変更。初回の内蔵スナップショットは135,766件のフィルターから、重複を除いてWebKitルールを生成したもの。実際に適用する分割リストには例外ルールの再掲があるため、設定のルール数はこれより多くなる。件数は実サイトの除去率を示さない。

設定 → ブラウザ機能 → 広告ブロックで次を変更できる。

- 標準：第三者の広告・追跡通信を遮断。初期値。
- 強力：同じサイト内の広告通信も対象。壊れるサイトでは標準へ戻すか、そのサイトを除外する。
- 広告枠の非表示：対応するCSSセレクターで枠や空白を隠す。初期値オン。
- 自動更新：利用中に最大1日1回、配布先のデータを確認。初期値オン。
- 手動更新、生成日時、ライセンス・原本へのリンク。

変更後は閲覧中のページを再読み込みする。サイト別除外は従来どおりサブドメインにも適用する。広告枠を隠す処理はJavaScriptをダウンロードせず、WebKitのcss-display-noneを使う。動画広告・広告ブロック検出への専用対策、変換できない高度なscriptlet等は含めない。Braveと同等の効果を保証するものではない。

## 更新の構成

`tools/filter-converter`はBrave adblock-rust0.13.3を固定して使うビルド専用ツール。Rustエンジンはアプリに入れない。LinuxのGitHub Actionsで1日1回、またはフィルター生成処理の変更・手動実行で公開リストを取得・変換する。MacやApple署名を使わず、無料の公開標準ランナーを利用する。

配布専用リポジトリの`filter-data-v1` Releaseにデータを保存し、必要ファイルをアップロードしてからmanifest.jsonを更新する。これはアプリ版ではなく、アプリのlatest Release・SideStore配信JSONには載せない。過去2世代のルールデータと、各世代の原本ZIPを保持する。

アプリには初期スナップショットも同梱する。更新はサイズ・SHA-256・形式を照合し、選択中のルールをWebKitでコンパイルできてから保存先ポインターを切り替える。通信やコンパイルの失敗では現在のルールを継続し、保存済みデータが壊れていた場合は内蔵版へ戻す。更新確認先へ履歴・閲覧URLを送信しない。

## お気に入りのアイコン

サイトのトップページにあるapple-touch-icon／icon指定を優先し、見つからなければルートのapple-touch-icon.png／favicon.icoを試す。お気に入りのパス・クエリは取得用URLから除外し、Cookie・ログイン情報・外部アイコン検索サービスを使用しない。サイトが宣言したHTTPSの画像配布先も利用する。

画像は192px以下に縮小して端末へ保存し、再表示のたびに取り直さない。通信は同時4件に制限。取得できなければ頭文字を表示する。設定の「サイト独自のアイコンを取得」で切替可能。プライベートのホームでは保存済み画像だけを使う。iOSがキャッシュを消去した場合は通常表示時に取得し直す。

## ライセンスと保存データ

個人・趣味での利用だがIPA・データは公開配信されるため、必要な表示・原本提供は維持する。

- Brave adblock-rust：MPL-2.0。アプリとは独立した変換ツールとして使用。
- EasyList/EasyPrivacy：公式のGPL3／CC BY-SA選択肢からGPL3を選択。
- AdGuard Japanese filter：GPL3。
- 変換したフィルターデータ一式：GPL3。改変・変換済みであることを表示。

各生成物の`filter-sources-REVISION.zip`に原本、ライセンス、変換コード、依存の固定情報を同梱する。アプリにも内蔵ルールの原本ZIPと通知を含める。採用先は`filters/sources.json`、ライセンス本文は`filters/licenses`。

Bundle ID、browser.jsonのschema1、ブックマーク・お気に入り・履歴、WebKitの保存領域、build14に戻した再生制御は維持する。フィルター設定・画像キャッシュは共通のライブラリデータとは分離している。
