# 0.16 ホーム画面での動画音声継続

「設定 → 音声・バックグラウンド再生 → ホーム画面でも動画の音声を継続」を追加。初期値はオン。選択中タブで実際に音声付き再生をしていた可視動画1件を対象とし、iPhoneのホーム画面へ戻る際にネイティブとWebの音声セッションをplaybackへ準備する。前面では従来の同時再生設定を使い、背景移行中は音声継続を優先し、戻った際にこの機能が変更したWebモードだけを復元する。録音・通話用セッションは変更しない。

WebKitによる移行時の停止には、同じWebView・frame・document・video・sourceと移行トークンを照合して、3秒以内に1回だけ復帰を試す。永続的な再生ループや無音による延命は行わず、短いbackground taskも更新しない。JavaScriptの実行や再生をiOSが許可しない場合は復帰できない。設定オフはこの補助を止め、WebKit標準の音声再生まで強制停止する設定ではない。

サイトのHTMLMediaElement.pause呼出しは元の動作をそのまま実行し、復帰の取消しだけを通知する。移行前の停止・終了・消音、PiP、再生先差替え、ページ遷移、タブ変更・削除、設定オフ、通話割込み、イヤホン切断、メディアサービス再起動で自動復帰を取り消す。リモートの一時停止も復帰予算を取り消す。Playは明示操作として元の対象へ渡す。通話終了等で自動再開しない。

元の認証済みWebKitプレーヤーを維持し、Cookie・認証情報・動画URLを外へ移さず、HLS・MSEのメディアURL抽出、DRMの解除、別AVPlayerへの置換、私的APIや追加entitlementは使わない。メタデータは短命のdocument/video ID・再生状態・表示面積だけで、ページURL・入力値・認証情報は収集・保存しない。全タブのWebViewを生成しない。既存のbuild14 updateMedia/mediaScript/audio policy、UIBackgroundModes=audio、bundle ID、schema1と保管庫・履歴・ブックマークの形式は保持する。新設定は独立UserDefaultsキー。

検証はCoreの復帰予算、実際のH264/AACとスクリプトの停止・復帰条件、ネイティブiOSの別origin iframe動画 → OSホーム → 復帰で元のメディア時計と背景経過時間の比率、停止後のホーム移行、設定保持、および既存の実音源・複数タブ同時再生を対象とする。無関係な全UI・保存形式往復・全アーカイブ検査は実施しない。Chromiumのhidden状態注入は方針検証だけで、iOSホーム検証とは区別する。

指定されたnicochannel.jpの公開動画URLと公開プレーヤーへのアクセス状況は調査記録で別に示す。会員ログイン・有料動画や実際のiPhone音声出力・画面ロック・通話・イヤホン操作の受け入れは、シミュレーターの時計進行から確認済みとはしない。サイトが自身で停止する場合やiOS/DRM/配信方式の制約は残る。

0.16.0 build103を配信済み。Python61件・Core85件・関連UI2件・Release実機用ビルド・匿名配信照合に成功。実際のOSホーム移行2回でアプリ状態3（背景）／Springboard状態4（前面）を記録し、信頼された非表示・復帰イベントの間に元の動画時計が進むこと、明示停止を維持すること、設定のオフ保持を確認した。テスト時だけ起動時に固定ページを用意し、無関係な広告ルールの初期化を外す。認証・自動再生の回避やホーム移行の模擬はしない。実際のiPhoneの音声出力・ロック・通話・イヤホン操作や、指定された会員動画自体の動作を確認済みとはしない。調査環境では指定動画URLが通常／iPhone User-AgentともHTTP404、公開プレーヤーJSはHTTP200だった。[配信検証記録](validation-0.16.0-2026-11-22.json)。
