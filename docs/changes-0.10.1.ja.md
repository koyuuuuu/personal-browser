# 0.10.1 スクロール停止時のバー復帰・ページ復旧・アプリ誘導対策

WebViewの実際のスクロール通知だけに依存していたバー復帰に、ネイティブの指の動きを監視する経路を追加しました。ページがtouchmoveを止めたりoverflowでスクロールを禁止したりしても、下向きの指操作でバーを戻せます。短いページ・スクロールがロックされたページでは上向きの操作でも戻します。通常の長いページでは従来のスクロール方向による非表示を維持し、単なる慣性・最下部の跳ね返りでは復帰させません。監視は同時認識・タッチ非キャンセルの公開APIで行い、リンク・ページの操作・横スワイプを奪いません。

ページの表示プロセスが終了した場合と一時的なネットワークエラーの場合に、選択中・前面のタブだけを自動復旧します。GET/HEADかつ送信本文のない要求に限定し、60秒内の自動再試行は1回までです。失敗したまま周期的に読み直す処理はありません。バックグラウンド中の失敗は前面に戻った際に確認します。POST等の送信、証明書・認証・ポリシー拒否、ダウンロードを自動再送しません。

読込失敗中はアドレスバーとツールバーを表示し、画面にも再読み込み（安全な要求のみ）とタブ一覧へのボタンを表示します。失敗中の表示は新しいタブ画像として保存せず、既存の最後のプレビューを保持します。再読込ループやフォームの自動再送を避けつつ、操作できない黒画面から戻れる構成です。

「設定 → ブラウザ機能」の「アプリへの誘導を軽減」を追加しました（初期オン、広告通信フィルターとは独立）。既存のサイト除外を共有します。Redditの既知のxpromo等と、app-upsell/smartbanner等の明示的な案内を対象に、「Continue in browser」等があればその選択を優先します。案内の非表示後に残ったスクロールロックや本文のinertを解除します。通常のログイン・年齢確認・権限・課金ダイアログを一括削除せず、別の正規ダイアログが残っている場合はロックを解除しません。開いたShadow DOMも範囲を制限して確認します。オフへの変更後に元のページを完全に戻すには再読み込みしてください。

Redditページのメニューには「Redditの旧Web表示で開く」を追加しました。利用者が選んだ時だけ同じパス・クエリをold.reddit.comへ渡します。通常の表示を強制的に旧サイトへ転送しません。サーバーが本文を配信しない制限、ログイン必須、アクセス拒否、閉じたShadow DOMなどは保証できません。

サイト互換スクリプトは新規の組込コードです。追加のOSSフィルター／第三者scriptletを取り込んだものではなく、遠隔から実行コードを取得しません。既存のEasyList/EasyPrivacy/日本語フィルターとライセンス構成を維持します。識別子の調査参考：[AdGuardの公開MobileAppルール](https://github.com/AdguardTeam/AdguardFilters/blob/master/AnnoyancesFilter/MobileApp/sections/mobile-app_specific.txt)。調査環境のReddit本体はチャレンジ画面を返したため、実サイト全体での成功は主張しません。

検証範囲はCoreの再試行・非再送・ホスト境界・指操作条件と、関連するネイティブUI3件に限定します。UIは実際にスクロール禁止したページで縦横両方向のバー復帰、表示終了コールバックを模した通知後の実際の再読込、実接続失敗の1回限定再試行とタブ一覧への復帰、アプリ案内・Shadow DOM・通常ログインの保持・オンオフ、および従来の通常スクロールを確認します。模擬通知を実際のOSメモリ圧迫／プロセス強制終了の実機試験とは数えません。

Bundle ID、schema1、保存先、Cookieストア、履歴・ブックマーク・各設定・通常タブのプレビュー形式は変更していません。0.10.0 build58と過去のタグ・IPAを保持します。build14のメディア処理と0.9/0.10の音声機能は変更しません。

配信済み版は **0.10.1 build60**（ソース `50df6642e5bfafa60d2dd90dfc3dfa7a2423ee70`）。Python54件・Core71件・関連UI3件・実機用IPAと配信の照合に成功しました。[機械可読の検証記録](validation-0.10.1-2026-11-03.json)。旧0.10.0 build58のIPA・タグを保持しています。
